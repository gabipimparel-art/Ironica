IRONICA — Official website prototype

LANGUAGE
The website is in English.

DOMAIN
The header displays https://ironica.com as the requested intended domain.
This does not mean the domain is registered or that the website is live online.

OPEN LOCALLY
1. Extract the ZIP.
2. Keep index.html, ironica-flag.jpg, and ironica-territory.jpg together in one folder.
3. Open index.html in a browser.

TERRITORY
The territory section uses the screenshot supplied by the user, where the territory is outlined in orange.

FICTIONAL LORE
The national details and rankings are presented as part of the fictional world of Ironica.
To publish online, upload these files to a hosting service and connect a domain you own.
